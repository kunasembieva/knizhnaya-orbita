# Обновление «Книжной орбиты» — этап 2

## Что изменено
- Главная страница показывает утверждённые 9 произведений, роли и творческие продукты.
- Карточка книги открывает личную страницу миссии.
- На странице книги добавлена кнопка «Читать онлайн» (ссылка берётся из `books.online_read_url`).
- Ученик может отправить текстовый ответ и прикрепить фото, видео, PDF или Word.
- Файлы загружаются в приватное хранилище Supabase `student-submissions`.
- В кабинете учителя убрано поле баллов; остаётся комментарий.
- Учитель может открыть временную ссылку на прикреплённые файлы.
- В кабинете ученика и публичных результатах скрыто отображение оценок.

## Важно перед публикацией
1. Сделайте резервную копию текущей папки проекта.
2. Не копируйте `.env.local` в архивы и никому не отправляйте его содержимое.
3. Откройте проект в VS Code и замените файлы из этого архива соответствующими файлами в своей папке.
4. Проверьте, что в локальном `.env.local` сохранены ваши действующие значения:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
5. Убедитесь, что ранее выполнена SQL-миграция `20261118_knizhnaya_orbita_update.sql`.
6. Для кнопки «Читать онлайн» добавьте URL документа в поле `online_read_url` каждой строки `books`. Сейчас ссылки на сами произведения не внесены.
7. После проверки локально можно отправлять изменения в GitHub/Vercel.

## Запуск локально
В терминале VS Code:
```bash
npm install
npm run dev
```
Откройте `http://localhost:3000`.

## Ограничения текущего этапа
- Поле `online_read_url` добавлено, но PDF/Word документы ещё нужно предоставить и загрузить.
- Обложки пока используют URL из `books.cover_url`; новые авторские обложки можно добавить отдельным этапом.
- Старые значения `score` в базе не удаляются, чтобы сохранить историю. Интерфейс больше не показывает оценки и новые проверки их не выставляют.
